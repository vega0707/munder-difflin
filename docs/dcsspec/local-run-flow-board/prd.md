# 流程 Run 看板（类 Cursor）

## 1. 需求概述

- **业务背景**：多 agent 跑完一条需求时，焦点乱跳、故事线断、输出散落在动态/任务/终端，难以回答「走到哪、卡在哪、每步产出什么」。
- **核心目标**：命令中心新增「流程」Tab：步骤看板 + 点开看动态与输出；默认不抢焦点；与「任务」「动态」分工。

## 2. 用户故事

| 角色 | 诉求 | 目的 | 优先级 |
| :--- | :--- | :--- | :--- |
| 人类负责人 | 打开「流程」看到步骤进度 | 知道整条需求走到哪 | P0 |
| 人类负责人 | 点开某步看动态与输出 | 不用多处翻找 | P0 |
| 人类负责人 | 有/无 plan 都有连贯步骤 | 故事线不断 | P0 |
| 人类负责人 | 阅读时不自动切 agent | 不被打断 | P0 |
| 人类负责人 | 失败可回看并点重试 | 复盘与续跑 | P0 |
| 人类负责人 | 多条并行时看楼层总览 | 不串线、不漏看 | P1 |
| 人类负责人 | 跨会话回看历史 Run | 事后复盘 | P1 |

## 3. 核心流程

1. 人类经既有入口下达需求 → 形成 Run。
2. 系统维护步骤：有 plan 用 plan 骨架；无则粗粒度事件自动串；并存时 plan 为骨、事件补洞并标来源。
3. 打开「流程」：默认当前进行中 Run；无则最近结束。多条进行中时以**楼层总览**呈现（弱化单 Run 独占）。
4. 步骤看板展示顺序与状态；默认不因更新切换选中 agent。
5. 点开一步：上动态摘要、下输出；一步严格对应一个 task。
6. 可选「去看 Ta」再导航；点步骤本身不切焦点。
7. 失败：Run=失败、失败步高亮、已完成可回看，并提供**重试**按钮。
8. 已结束 Run 跨会话持久可查。

## 4. 功能拆解

| 模块 | 功能点 | 说明 |
| :--- | :--- | :--- |
| 命令中心 | 「流程」Tab | 与任务/动态并列，不替换 |
| 流程 | 楼层总览 / Run 切换 | 多进行中合并总览；历史可切 |
| 流程 | 步骤看板 | 顺序、状态、摘要 |
| 流程 | 步骤详情 | 动态摘要 + 输出 |
| 流程 | 失败重试 | 失败呈现上的重试入口 |
| 流程 | 历史 | 跨会话持久 |
| 任务/动态 | 只读协同 | 职责不变 |

## 5. 核心对象（业务语言）

- **Run**：一次需求执行；进行中 / 成功 / 失败。
- **步骤**：有序节点；等待 / 进行中 / 完成 / 失败（可选跳过）；**严格 1:1 对应一个 task**；来源 plan 或自动。
- **步骤动态 / 步骤输出**：点开即见。
- **Plan（可选）**：步骤骨架。

## 6. 业务规则

1. Run：下达 → 成功/失败；可跨多 task（多步串联）。
2. 步骤来源混合；无 plan 时偏粗粒度。
3. 默认不切 agent 焦点。
4. 三 Tab 不合并不替换。
5. 失败可回看 + 重试按钮。
6. 多进行中 → 楼层总览（Q3=B）。
7. 历史跨会话持久（Q8=B）。
8. 一步 = 一个 task（Q10=B）。

## 7. 验收标准（摘要）

- 可见「流程」Tab；任务/动态行为不变。
- 有/无 plan 均有可读步骤；点开可见动态+输出。
- 默认不自动切 agent。
- 失败高亮可回看，有重试。
- 多进行中为楼层总览；历史跨会话可查。
- 一步对应一个 task。

## 9. 不做（本迭代仍不做）

- 不替换任务/动态 Tab  
- 不做 Run 对比/导出/分享  
- 不做双轨两套步骤 UI  
- 不做细碎状态机（等人/阻塞等独立态）  
- 空态不嵌完整派发台  
- 不默认自动跟随切 agent
